# fjord.daemonless.io

Website for [fjord](https://github.com/daemonless/fjord), the app store for
FreeBSD containers. Built with [Zensical](https://zensical.org) and published
to GitHub Pages on every push to `main`.

```sh
pip install -r requirements.txt
make serve        # http://localhost:8002
```

Pages live in `docs/`; screenshots go in `docs/img/`.
